# INFLORO — Next.js starter

Built from scratch with Next.js App Router, TypeScript, Tailwind CSS v4, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included in this first step

- Home / landing page at `/`
- Responsive navigation with a working Features dropdown
- Working light/dark theme toggle (saved in local storage)
- Mobile navigation menu
- Purple brand styling, subtle motion, hover states, and responsive dashboard illustration
- The supplied Infloro logo at `public/infloro-logo.jpg`
- No external/public stock imagery. The dashboard visual is built with HTML and CSS.
